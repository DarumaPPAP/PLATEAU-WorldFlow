# plateau-area-design

## Trigger

地点の承認後、取得範囲や重複の統合・共有・分離を比較するとき。

## 入力

承認済み地点、候補範囲、座標参照系、Datasetの出典・粒度。

## 出力

候補範囲、重複の扱い、影響と承認対象。座標系が揃った根拠がある場合だけ面積を比較する。

## 中止条件

地点が未確定、座標系が不明なら範囲の確定を保留する。概略図の作成・範囲比較は読み取り専用で行い、CityGML取得やScene変更には別のEditor承認を求める。

## 責務と実行境界

Read-only APIのCoverage に紐づく `area` / `preview` / `png` イベントを使う。利用可能、不在、未確認のコードをそのまま比較し、確認できたメッシュだけで完結する案も提示する。複数地点を比べるときは地点ごとにセッションを持ち、未確認や異なる CRS の重複面積は `null` とする。共有・分割の方針はユーザーが決め、実際の地理的な分割処理は後続工程に引き継ぐ。

`NOT_COMPUTED` の面積は `null` として扱う。CRS 未確認の画像は地図上の厳密な位置に使わず、メッシュの概略図として表示する。地点や Coverage が変わったら、旧 Plan と PNG は `STALE` とする。CityGML 取得・Import は実行禁止。

実際のImport処理は[Import Skill](../plateau-city-import/SKILL.md)が担当する。範囲選択の同意をImportの承認に流用しない。

`spatialFit` を確認してから範囲案を提示する。施設・駅・作品舞台では、出典付き座標の誤差範囲全体が同一 CRS の確認済み選択メッシュの和集合に収まることを確認する。未確認セル、覆われていない隙間、根拠のない座標変換は包含判定に使わない。明示メッシュではメッシュ可用性を報告し、施設の包含を断定しない。

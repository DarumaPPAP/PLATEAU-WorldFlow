# 名称とブランド

PLATEAU-WorldFlowは独立した非公式OSSです。国土交通省またはProject PLATEAUによる開発、承認、公式サポートを受けているという表示を避けます。

- RepositoryとPackageのREADMEに独立性を記載します。
- 公式ロゴやVIを転載・改変する場合は公式の利用条件と必要な許諾を確認します。
- 独自のロゴ・アイコンを採用する際は素材の出典と利用条件を確認します。
- 製品名・広報物を公開する際の確認先は [PLATEAU公式ハンドブック](https://www.mlit.go.jp/plateau/libraries/handbooks/) と [サイトポリシー](https://www.mlit.go.jp/plateau/site-policy/) です。

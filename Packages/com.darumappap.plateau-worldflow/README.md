# PLATEAU WorldFlow

`com.darumappap.plateau-worldflow` は、PLATEAU都市モデルの調査・計画・Importを支援するUnity Editor向けPackageです。Phase 0の現時点ではメタデータと文書のみを用意しています。Unityでの導入・コンパイル・動作は未検証です。初期検証基準は Unity `6000.3.10f1` 以上です。

初回Setup、SDK診断、承認付き導入はPR-02の対象です。都市モデルのImportは後続Phaseの対象です。利用者向けのGit導入は動作確認後にPackage subfolderと安定Tagを指定して案内します。

本プロジェクトは独立した非公式OSSです。国土交通省およびProject PLATEAUによる開発、承認、公式サポートの対象外です。SDK、都市データ、第三者資産は同梱していません。[MIT License](LICENSE) · [第三者表示](THIRD_PARTY_NOTICES.md)
